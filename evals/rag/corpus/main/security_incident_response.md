# Security Incident Response Guide

## Reporting a phishing email

Do not click links or open attachments. Use the "Report Phishing" button
in Outlook, which sends the message to the security team and removes it
from your inbox. If you already clicked a link or entered your password,
change your password immediately and call the help desk at extension 5000.

## Severity levels

SEV1: customer data exposed or production fully down — security on-call is
paged immediately. SEV2: a single system compromised or degraded, no data
exposure confirmed — response within 1 hour. SEV3: suspicious activity with
no confirmed impact — response within 1 business day.

## Malware alert on a laptop

When the endpoint protection agent shows a malware alert, disconnect the
laptop from the network (Wi-Fi off, cable out) but do NOT turn it off, so
memory evidence is preserved. Then call the help desk.

## Contact and escalation

Security on-call: extension 5100, available 24/7. For anything involving
customer data, the Data Protection Officer must be informed within 24
hours.
